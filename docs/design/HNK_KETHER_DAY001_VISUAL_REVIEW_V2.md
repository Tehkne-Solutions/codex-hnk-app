## 1. Trigger

The first immersive walkthrough fixed the product grammar but exposed a second-order art-direction issue: several acts still read as premium dark UI rather than a living codex / impossible sacred instrument.

The Creator review explicitly rejected the earlier `phrase -> continue -> phrase` feeling. Experience V2 solved that structural problem. Visual Review V2 now addresses materiality without reopening the six-act grammar.

## 2. Boundaries

This pass MUST NOT:

- alter the canonical Day 001 text;
- invent Dai Koo Myo geometry;
- publish an unapproved Kether sigil;
- publish Gneo Geo;
- choose an audio frequency or preset;
- alter XP or progression rules;
- turn spiritual or phenomenological language into scientific proof;
- decorate the Origin simply because later acts become richer.

## 3. Preserved element — Limiar

The fertile black, point, rings and restrained threshold remain the visual anchor.

Decision: **preserve**. Kether must begin with cosmogony, not visual abundance.

## 4. Material transformation by macroact

### II · Revelação — Instrument Cabinet

Goal: remove the generic card feeling from the symbolic key chamber.

- symbolic field receives an engraved/instrument-like inner frame;
- light behaves as state and focus, not decoration;
- radial geometry stays abstract and non-canonical;
- selected meaning gains material depth without pretending to be a sacred artifact.

### III · Jachin — Illuminated Dark Folio

Goal: make the canonical doctrine feel like a page-object rather than a content card.

- subtle folio grain created entirely with CSS gradients;
- illuminated drop cap for the doctrine opening;
- restrained Roman numeral watermark;
- margin notes become editorial rails;
- no external image or invented operator is introduced.

### IV · Boaz — Obsidian Instrument

Goal: communicate contraction and rigor through material and verticality.

- darker iron/obsidian field;
- reduced ornamental luminosity;
- distraction inputs read as blades/instruments rather than standard textareas;
- focus state is a precise material response, not a gamified intensity reward.

### V · Pilar do Meio — Luminous Convergence Chamber

Goal: make integration spatial.

- a central luminous axis organizes the field;
- manuscript and vocal/reflection instruments share one geometry;
- concentric rings remain abstract system geometry;
- reduced motion stays authoritative.

### VI · Passagem — Spatial Memory

Goal: the first spark must feel like a changed cosmology, not a reward modal.

- Tree field gains scale and optical depth;
- Kether receives dominant light-state authority;
- background gains restrained stellar geometry;
- reward remains clearly separated from server-authoritative completion logic.

## 5. Implementation strategy

The art pass is isolated in `day001-art-pass-v2.module.css` and wrapped by the Day 001 page.

This deliberately keeps:

- Experience state machine unchanged;
- canonical loader unchanged;
- Auth/Vault/Practice/XP contracts unchanged;
- original immersive stylesheet available as the structural baseline;
- the new visual layer easy to review or revert independently.

## 6. Approval criteria

The candidate passes technical review only if:

1. Foundation CI remains green;
2. Experience QA Gate remains green;
3. Visual Proof V2 renders all 6 acts at desktop and 390px;
4. walkthrough remains structurally immersive;
5. reduced motion remains valid;
6. no unapproved asset/sigil/audio is introduced;
7. human review confirms the result is materially richer without returning to fantasy clutter or SaaS cards.

Creator approval remains required before this becomes the visual baseline for Days 002–005.
