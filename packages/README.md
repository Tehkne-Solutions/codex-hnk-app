# packages

Pacotes compartilhados da HNK Platform.

Planejados:
- `domain` — regras HNK puras;
- `codex` — parser/normalizador do conteúdo canônico;
- `ui` — design system e tokens;
- `audio` — presets/engine;
- `crypto` — contratos do Diário;
- `assets` — registry/factory;
- `analytics` — eventos mínimos de produto.

Regra: conceitos de domínio não dependem de Expo, Next.js ou Supabase.
