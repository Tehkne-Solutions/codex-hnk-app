# HNK Platform

Plataforma oficial do **HNK Codex Interativo 365**.

Este repositório contém o aplicativo mobile, a experiência web/admin e os pacotes compartilhados da plataforma HNK. O conteúdo canônico permanece no repositório `Tehkne-Solutions/hnk-codex-365`, que atua como fonte editorial de verdade.

## Stack oficial

- Expo / React Native
- Next.js
- TypeScript
- Supabase
- Vercel
- Web Audio API
- GitHub Actions
- pnpm + Turborepo

## Princípio arquitetural

`hnk-codex-365` publica conteúdo canônico; `codex-hnk-app` consome, apresenta, gamifica e registra a experiência do usuário.
