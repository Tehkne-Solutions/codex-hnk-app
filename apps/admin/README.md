# apps/admin

**HNK Studio** — cockpit interno de produção da plataforma.

Tecnologia alvo: Next.js + TypeScript + Supabase + Vercel.

Primeiro escopo:
- status dos 365 dias;
- sincronização com o Codex canônico;
- Asset Registry;
- aprovação/rejeição de assets;
- presets de áudio;
- previews mobile/web;
- publicação e auditoria.

O Studio não substitui `hnk-codex-365` como fonte canônica editorial.
